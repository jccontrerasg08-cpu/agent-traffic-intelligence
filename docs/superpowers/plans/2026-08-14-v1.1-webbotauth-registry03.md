# V1.1 Current Web Bot Auth Alignment Implementation Plan

> **For agentic workers:** continue task-by-task with TDD. Before every repository mutation, re-check direct primary sources and all open PRs. Keep V1.1 work inside PR #8 unless a genuinely independent stream justifies another PR.

**Goal:** finish current Web Bot Auth interoperability, source-trust, offline-discovery, and standards-drift work while preserving V0/V1 privacy, scoring separation, and offline-default guarantees.

**Current architecture:** V1.1 now separates generic CIMD JWK Sets from strict HTTP Message Signatures Directory semantics, uses explicit `Signature-Agent` interoperability/discovery profiles, supports strict `client_id` retrieval, verifies directory response authority binding when available, and persists only privacy-safe derived bindings.

**Tech Stack:** Python 3.11+, RFC 9421 through ATI's optional `http-message-signatures` adapter, RFC 9530 digest validation, standard-library JSON/URL/data handling, existing source cache/fetcher, pytest/Hypothesis/Ruff/Mypy, GitHub Actions.

## Global Constraints

- Current Agent Card profile is `draft-meunier-webbotauth-registry-03`.
- Current directory provenance is `draft-meunier-webbotauth-httpsig-directory-00`.
- ATI's `StandardsProfile` currently pins `draft-meunier-webbotauth-httpsig-protocol-01`; direct upstream draft source is the authority when search indexes lag.
- Historical architecture/directory drafts remain compatibility/history only and are not current provenance labels.
- V0 output remains unchanged when verification is disabled.
- Verification directly changes only `identity_confidence`, never automation/AI/risk scores.
- Raw source IPs, signature bytes, Authorization, cookie values, and private keys never enter persisted output.
- `ati analyze` remains offline by default and never refreshes sources implicitly.
- `UNAVAILABLE`, `STALE`, and operational `ERROR` never become `FAILED` by themselves.
- Core stays zero-runtime-dependency; crypto remains in `[verification]`.
- PR CI remains hermetic with no live DNS/HTTP.
- Normally keep no more than 2–3 active PRs; all current V1.1 work remains in PR #8.
