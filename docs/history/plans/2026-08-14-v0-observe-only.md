# V0 Observe-Only Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a git-ready open-source V0 that parses JSONL access logs, extracts privacy-safe features, recognizes known AI/bot User-Agents, emits explainable evidence, and computes four independent scores.

**Architecture:** Python 3.11+ library and CLI with zero runtime dependencies. Each subsystem has a small interface: parser -> normalized event -> feature/session state -> identity/rules -> evidence -> scoring -> detection. External fingerprints and verification can be supplied as fields but are not generated by V0.

**Tech Stack:** Python standard library, pytest for tests, Ruff/Mypy as development tooling, GitHub Actions, JSON registry, JSON Schema documentation.
